## Changes

- Structural flags now contain only enter, exit and give-way. Live stop changes at known intersections leave the snapshot and logical signal schedule intact. Both capture and later validation still reject a stopped waypoint without a verified junction association. Physical native stop/pinning checks are unchanged; a red light does not become a permanently closed road section.
- Geometry, waypoint identity/index, neighbour contracts including null-versus-empty, lane links, agent/car permissions, canonical speeds, road IDs, junction associations/arrays/groups/exits/name and configured signal timings still invalidate or reject changed data. Temporary closures remain live and can reopen in the same frame. Unexplained speed changes retain their existing repeated-exception behavior.
- Scene discovery belongs to the planner/save lifetime. Genuine structural or gate rebuilds reuse the known live scene. Missing-scene periodic retry, a destroyed Unity scene object or changed CityManager triggers rediscovery; save load and clock-rate replacement create a fresh planner. This removes repeated global road-scene searches during ordinary snapshot churn.
- Station discovery uses Unity's unsorted API, then orders the small result by instance ID to preserve the old duplicate-name ordering. Gates and stations still perform periodic full discovery, including inactive objects, to detect additions/replacements. Merely retaining the existing component list would miss new inactive gates/stations. **These periodic searches remain unbounded and may still hitch; no measured native improvement is claimed for the station API change.** A complete bounded discovery/lifecycle mechanism is separate work if the playtest confirms it is needed.
- Diagnostics retain the first mismatch reason and node/junction index through rebuild. Each snapshot start logs its reason and frame. Observation summaries count reasons and scene/station searches. Up to four preparation/closure samples exceeding 16 ms are logged per observation with frame, realtime and both durations, enabling correlation without logging every frame. Existing door/station/RLO maxima remain available. These timings are not total frame cost.

Production delta: four Runtime files (`TrafficRoadNetwork.cs`, `RoadRoutes.cs`, `MultimodalRoutes.cs`, `PersistentCityMod.cs`). The frozen candidate starts from the installed reviewed source and excludes four concurrent Compatibility edits in the moving checkout; those files were preserved.

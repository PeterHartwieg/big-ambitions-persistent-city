# F0: guarded ground-floor interior population prototype

Opting in keeps existing physical residents around a ground-floor shop's first entrance. Default off preserves the legacy hidden predicates, release path, first-construction gate and save payload. Flat settings default to off /60 m release radius /24 pedestrians /12 vehicles, with bounded clamp/default diagnostics. Admission is now release radius /1.2 (default 50 m), so bodies are acquired inside a buffer. Every retained binding, including successful arrival handoffs, obeys the strict release radius and sub-caps.

First construction/preflight always waits until **outside**, even with the feature on; an inside reload runs background population until exit, then re-entry can retain physical bodies. Auxiliary scene unloads outdoors leave street bodies alone. Save and hidden jumps observe before release, including exceptions; exit/load/scene unload while inside, time machine and disable clear the runtime view.

**Drawing is a no-op:** detached layouts and private player-relative culling have no verified scoped override. This does not yet show the street through windows. [Vanilla discovery and F1–F3 limits](../plans/track-f-interior-view.md). Independently written from vanilla DLLs and our code, with no third-party implementation or A-stack dependency.

## Step A1 resident inspector - 30 October 2026 (offline only)

Implements slice A1 of the [step A plan](../plans/step-a-inspector-traits-choice.md), updated first with Peter's 15:46 JST decisions. In the normal view, hovering an own walking resident highlights them and a click opens a small popup with name, home and work addresses (links that open the native map through `CityMap.FocusOnBuilding`, the game's own "show on map" call), personality in words from existing facts (persona rules, walking tolerance, car/transit/fare preferences, an existing food preference), the resident's own story, current destination with the reason, and today's breakfast, lunch and dinner. Only the latest meal record exists before schema 17, so earlier meals today read "not recorded" and later or undecided ones "unknown"; uncertain receipts read "not yet confirmed". Read-only: no schema, economy, choice, schedule, rival or RLO change.

**Performance design.** Picking runs in `PopulationRuntime.Update`, inside mod-work attribution, only after the cursor moved by at least one pixel and at most every 50 ms. With the popup closed and the cursor still it does nothing; while a walker is hovered it projects that one body per frame. A pick is one screen projection per active own walker (default ceiling 48) over the bindings dictionary, with no route search, raycast or allocation. Popup content is built on click and refreshed once per second while open; `OnGUI` only draws cached strings. `PopulationRuntime.InspectorTiming` reports cumulative Update and draw cost by mode (closed, hover, open), picks and popup builds. The rig probe's component slots grow from 13 to 15 to time `ResidentInspector.Update` and the whole `PopulationRuntime.OnGUI`. `OnGUI` sits outside the primary Update scope, so add it to combined mod work separately; it is not nested.

**Offline measurement (Debug xUnit run on this PC, .NET 10, not Unity/Mono):** `ResidentInsight.Capture` plus text **3.69 us** per popup build; scoring 48 walkers for one pick **1.07 us** (projection excluded). The steady pick path (throttle plus 48-walker scoring) allocates **0 bytes** over 100,000 frames. Offline ceilings asserted: capture < 200 us, pick < 50 us. These do not certify native frame time.

**Review round 2 fixes (offline).**
- **Current cursor and gesture ownership (Astra r2-1, Opus r2-1).** Ownership is now decided from the current native cursor (`Input.mousePosition`, converted to GUI coordinates), once per frame inside the `MouseController.Run` prefix (`Run` can be called twice per frame). It is no longer read from the last OnGUI event. The rule is the pure `InspectorPointerGesture`:
  - A left-button press on the popup or a highlighted walker, under the same view and native-UI checks and with no native hold-walk in progress, makes that whole press-hold-release gesture the inspector's. `Run` is skipped until every button is up, wherever the cursor goes, and the game's `LeftButtonHeld`/`RightButtonHeld` are cleared when the gesture ends.
  - Every other gesture stays native throughout, including a hold-walk released over the popup or a walker. On non-click frames `Run` always runs, so the game sees releases, hover outlines and cursor state.
  - The walker click is accepted in OnGUI only when the guard gave that frame's press to the inspector, so the guard and the click never disagree. Without the guard, the inspector falls back to the direct checks.
  - Picking also uses the current cursor.
- **Placement mode (Opus r2-2).** `PlacementSystem.IsInPlacementMode` is excluded.
- **Build inputs.** The build now also references `UnityEngine.InputLegacyModule` and `BigAmbitions.PlacementSystem`, read-only.

Three new tests cover the gesture rule: moving in and pressing, then dragging and releasing outside; a press outside and a hold-walk released over the inspector staying native; and press-and-release in one frame or a lost release. The round-2 gate run was not completed before its harness commit `c7351c9`; results for the final head are under round 3.

**Review round 3 fixes (offline).**
- **Popup scrolling no longer zooms the camera (Astra r3-2).** The game's `PedestrianCam` zooms on the mouse wheel unless native uGUI is under the cursor or the static `PedestrianCam.blockCameraZoom` is set; the IMGUI popup is neither. Round 3 set that shared flag; round 4 replaced this (below).
- **The mouse hook fails open (Opus r3-2).** `MouseRunPrefix` wraps the decision in try/catch. On an exception it returns true (native handling), resets the gesture, logs once and stays disabled until detach.
- **Left button only (Opus r3-3).** Only left presses are taken from the game; right-button gestures over a walker or the popup stay native. The inspector has no right-click action.
- **Evidence record (Opus r3-1).** The round-2 placeholders and test count are replaced; the round-3 gate run was cut off before it finished, so the validated results are recorded under round 4.

**Review round 4 fixes (offline).**
- **Wheel guard at the camera input (Astra r4-1, Opus r4-3).** The inspector no longer writes `PedestrianCam.blockCameraZoom`. Native `DialogUI.ShowDialog`, `PurchaseUI.Open` and customization windows own that shared flag. A prefix/postfix on the camera's private `UpdateInput(float)` saves its `distance` before input and restores it afterwards, but only while the current cursor is on the open popup in the normal view. Native blocks therefore work in either acquisition order, and a native window opening or closing while the cursor rests on the popup is never overridden. The postfix fails open: on an exception it logs once and disables itself. Undoing the distance also undoes a gamepad zoom on that frame, while the cursor is on the popup.
- **No stale input claims (Opus r4-2).** Click and wheel claims now require the inspector to have been updated this frame or the previous one. The early return taken while routes prepare calls `inspector.Suspend()`, which hides the popup's input claims and clears hover without dropping the selection. A hidden popup or an old walker rectangle never swallows a world click, and the wheel is never held.

### Why these seams

Tests and regression tools read `PhysicalPopulation.cs` as text and extract ranges between two markers. Every such range stays inside one file:

- `BeforeAdvance` to `Update` (`interior_wiring.py`) and `SelectionCandidate` to `Outdoor` to the `PlanQueues` summary (`physical-selection-regression/run.py`) put the save hooks, `Update`, `Outdoor` and `PlanQueues` together in Selection;
- `PlanQueues` to `TryLine` (`VisitorBodyTests`) and `Standing` to `TryLine` (`optional-stop-regression`) end Selection after `TryLine`;
- `ObserveCar` to `// Inspector picking` (`PresentationBoundaryTests`) keeps picking in Following.

### Readers of the source text

These now read the four files concatenated (main, Following, Queues, Selection); nothing else in them changed:

- `tests/FocusIndependentInputsTests.cs`, `tests/PresentationBoundaryTests.cs` (two reads), `tests/PresentationGridTests.cs`, `tests/VisitorBodyTests.cs`;
- `tools/physical-selection-regression/run.py` and `interior_wiring.py`, `tools/optional-stop-regression/run.py` (not run before release; `optional-stop-regression` already failed at the base, because its `MotionPermission(` and `TryAwaitArrival(` markers no longer exist).

`tests/PersistentCity.Tests.csproj` compiles the three new files next to `PhysicalPopulation.cs`. No other csproj includes it by path; `tools/build.py` globs `Runtime/*.cs`.

## Verbatim check

Run from the repository root:

```python
import subprocess
from pathlib import Path
before = subprocess.check_output(['git', 'show', '300ddb8:Runtime/PhysicalPopulation.cs']).decode().replace('\r\n', '\n').split('\n')
def body(name, wrapper):
    lines = Path(f'Runtime/{name}').read_bytes().decode().replace('\r\n', '\n').split('\n')
    assert lines[0].startswith('// '), name  # the one-line header comment
    return lines[1:] if not wrapper else lines[1 + 14:-3]  # usings+namespace+class header (14), closing braces (3)
main = body('PhysicalPopulation.cs', False)
pieces = {n: body(f'PhysicalPopulation.{n}.cs', True) for n in ('Selection', 'Queues', 'Following')}
text = '\n'.join(before)
# 1. Every moved block is one contiguous, unchanged run of the original file.
for n, lines in pieces.items():
    assert '\n'.join(lines) in text, n
    print(f'{n}: {len(lines)} lines, contiguous in the original at line {text[:text.index(chr(10).join(lines))].count(chr(10)) + 1}')
# 2. Nothing lost or added: the sorted non-blank lines before and after are identical.
after = main + [l for p in pieces.values() for l in p]
assert sorted(l for l in before if l.strip()) == sorted(l for l in after if l.strip())
# 3. Reassembled in original order (main head, Selection, Queues, Following, main tail), the file is the original
#    except for the blank separator line at each of the four seams.
cut = main.index('        public void ObserveForSave()')
rebuilt = main[:cut] + [''] + pieces['Selection'] + [''] + pieces['Queues'] + [''] + pieces['Following'] + [''] + main[cut:]
assert rebuilt == before, 'order'
print('verbatim: OK,', len([l for l in before if l.strip()]), 'non-blank lines before and after')
```

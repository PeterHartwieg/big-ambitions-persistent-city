## Conditional probe and isolation

[IcecreamFeasibilityReader.Read(existingRegistration)](../../Runtime/IcecreamFeasibilityReader.cs) pins the exact ice cream ID through the existing private-constructor descriptor and [shared reader](../../Runtime/DirectStockShowcaseReader.cs). One descriptor line is the only shared C# change. Read branches/refusals/outputs and donut/cupcake/salad facades and functional cases remain identical. No new holder abstraction is justified without loaded evidence.

Invoke explicitly on the Unity main thread using an existing registration field, reselecting after reload. No public arbitrary product selector, bridge command, hook, timer, poll, city scan, scheduled/gameplay caller or persisted native-data cache. Conditional acceptance requires a loaded `ShowcaseShelf`, exact ice cream whitelist, consuming resources, single same-ID nonnested cargo, no shared outputs, supported full-service/bag fields and one exact explicit price. The equipment name is observed output, never authorization: `icecreamcounter` as a workstation refuses even with finished cargo; mixture/shared inputs refuse. A non-showcase finding stops this probe and requires further evidence/review before any extension.

Inherited bounds are 2,000 furniture and 128 menu/price/cargo/output/whitelist/tag entries. Results are detached with read-only equipment. `DirectStockFieldsVerified` certifies conservative field shape only; `Eligibility` always stays Unknown, including native tags/staff/requirements/checkout. `RawProductUnits` counts direct showcase cargo; `RawBagUnits`/`RawCounters` are one unqualified shared pool, never meals/capacity/reservations. Zero stock/bags remain known zero; empty bag cargo refuses. Invalid business/price/identity/collections/whitelist/resource, workstation/converted/shared/nested cargo, counter/product overlap and overflow refuse. Main-thread invocation is required; concurrent mutation is not an atomic snapshot.

No checkout seam is added. `ProcessCustomer` creates random data and writes native state; existing `NativeFoodMarket.Buy` constructs customers/orders for the current three products. Rig proof observes natural native ice cream checkout and daily settlement only. Reader-side synthetic customers, recipes, cargo, orders or cash are excluded.

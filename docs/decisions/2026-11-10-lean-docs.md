# Lean docs, 10 November 2026

Peter, 10 November 2026, asked what slices should write from now on: "As lean as possible, agents can get lost otherwise." The docs folder held 261,884 lines against 52,787 lines of production code, and under 2 percent of what a search returned was current.

## Rule

- The tree keeps only what an agent needs to do the next slice: `AGENTS.md`, `README.md`, the [roadmap](../roadmap.md), [behaviour](../behaviour.md), the [glossary](../glossary.md), the [rig checklist](../rig-checklist.md), the contract pages (`rlo-contract.md`, `rlo-bridge.md`, `save-format.md`, `food-product-metadata-api.md`, `stationary-citizens.md`), owner decisions in this folder, and plans whose slices are still open.
- A slice writes no docs unless its task names the file. Evidence, before/after perf numbers and in-game checks go in the PR description. There is no per-slice checks file and no per-slice perf file.
- The coordinator copies a merged slice's in-game checks into the rig checklist and updates the roadmap.
- A plan leaves the tree when its last slice merges. Results files, measurement JSON, review transcripts and PR descriptions never enter it.
- Before adding a page, ask whether the roadmap, the behaviour page or a decision can carry it in a few lines.

## What moved

Everything removed on 10 November is in the tag [`docs-history-2026-11-10`](https://github.com/PeterHartwieg/big-ambitions-persistent-city/tree/docs-history-2026-11-10): `docs/checks`, `docs/perf`, `docs/reviews`, `docs/archive`, the plans of merged slices, `CHECKS.md` and the October design pages. Links from kept pages point into that tag. Nothing in it is required reading.

## What this replaces

- The [6 November delivery rules](2026-11-06-delivery-rules.md): "each slice writes its checks in its own checks file", "a slice edits only `docs/checks/<slice>.md` and `docs/perf/<slice>.md`" and "every slice still has a perf file".
- The 30 October practice of a perf file per slice. The perf gate itself is unchanged, and a slice still measures and reports.
- `CHECKS.md` and the README status table. The roadmap lists what is done and what remains.

## Still open

- `tools/` holds about 60 regression tools that are not run before release, with their evidence files. Removing them is roadmap row X5.
- Slices in flight on 10 November were briefed under the old rule and may still add a checks or perf file. The coordinator folds those into the PR description and the rig checklist at merge.

# Optional-stop physical regression

Run `python tools/optional-stop-regression/run.py` with .NET 10 on PATH. The script extracts the production optional-stop observation and queue-reservation methods from `Runtime/PhysicalPopulation.cs`; doubles represent native movement only. It checks approach, facing, retained identity/body, immutable deadlines, rain, reconstruction, blocked-path cancellation, return retries and queue spot conflicts. No game is launched. Native geometry/animation/performance remain unverified.

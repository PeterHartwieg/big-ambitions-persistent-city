# Vehicle ownership regression

Run `python3 tools/vehicle-ownership-regression/run.py`. Use `--source-root /path/to/frozen/source` to check a candidate snapshot.

The harness compiles the actual `VehicleScriptOwnership` implementation and extracts the actual `RandomAmbient`, `Ordinary` and body ownership-validation methods. Controlled Unity doubles cover live addition/removal/reparenting, inactive services and subclasses, destroyed/missing components, assembly policy boundaries, nested checks, cleanup after a query exception, bounded buffer retention, stable type-cache size, pool reuse, and changed native body/path/marker identity. The unchanged legacy predicate is an independent oracle for fixture decisions. No game assemblies are needed.

Since 27 October the body memoizes its component verdict for one ownership epoch within one frame. The harness also extracts the actual epoch members, the five native mutation wrappers (`LoadNative`, `TargetNative`, `StopNative`, `RemoveNative`, `ExpireNativeStop`) and the per-frame taxi classification. It checks verdict reuse within an epoch, live reference and state checks inside an epoch with no component search, a foreign component added mid-epoch being seen at the next epoch or frame, a search that advances the epoch or throws, claims made inside each native call being seen as soon as the wrapper returns (also when it throws), and the per-frame active-taxi count with its one-frame lag. Before compiling, `run.py` checks the call sites the doubles cannot run: `Update` and `BeginNativeFixedStep` advance the epoch first, `Release` advances it before its verdict, every wrapper advances it in `finally`, `TryAcquire` targets through the wrappers before its final verdict, and no raw native mutation appears outside the wrappers.

Run the sibling `native-command-regression` harness for deferred physics, including ownership loss inside the final permission callback. These offline checks do not establish native Unity query parity, allocation behavior or frame-time improvement; those require isolated game testing.
